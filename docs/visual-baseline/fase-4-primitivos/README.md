# Fase 4 — Primitivos, marca e conferência visual

Capturas produzidas em 2026-07-28 com `npm run capture-baseline -- fase-4-primitivos`, contra o Vite local e mocks de API do próprio capturador.

Há uma imagem em 390×844 e outra em 1280×800 para as 12 superfícies: acesso, troca de senha, painel, chamada, inscrição pública e as sete rotas administrativas. `attendance-offline-*` é uma evidência adicional do fluxo offline, não uma décima-terceira superfície.

As rotas administrativas foram capturadas com a sessão de coordenação e fixtures de anos, calendário, turmas, alunos, catequistas, inscrições e relatório. A conferência humana e a checklist estão registradas em `docs/qa/reports/2026-07-28-fidelidade-primitivos-marca.md`.
